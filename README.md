# 🛒 API CRUD de Produtos – Spring Boot + PostgreSQL

Esta é uma API REST desenvolvida com Spring Boot, Spring Data JPA e PostgreSQL para gerenciamento completo de produtos. Possui estrutura organizada seguindo boas práticas (Controller, Service, Repository) e inclui tratamento global de exceções. Todos os endpoints foram testados no Postman.

---

## 🚀 Tecnologias Utilizadas

- Java  
- Spring Boot  
- Spring Web  
- Spring Data JPA  
- PostgreSQL  
- Lombok  
- Maven  

---

## 📦 Funcionalidades

✔ Criar um produto  
✔ Listar todos os produtos  
✔ Buscar produto pelo ID  
✔ Atualizar produto por ID  
✔ Deletar produto  
✔ Tratamento global de exceções com respostas padronizadas  

---

## 🧠 Aprendizados Adquiridos

- Compreensão prática de como construir uma API REST completa com Spring Boot.  
- Aplicação do padrão Service Layer para separação clara de responsabilidades.  
- Utilização do Spring Data JPA para persistência, consultas e manipulação de dados.  
- Configuração e integração de um banco PostgreSQL com Spring.  
- Modelagem de entidades utilizando JPA e anotações fundamentais.  
- Uso do Lombok para reduzir boilerplate e tornar o código mais limpo.
